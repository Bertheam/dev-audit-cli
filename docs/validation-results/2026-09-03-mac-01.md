Les racines automatiques sont heuristiques. Ce passage ne produit donc
volontairement aucun `MISSING` ni `NO_REFERENCE_FOUND`. Les correspondances
positives restent autorisées lorsqu'une version exacte est démontrée.

## Corrections déclenchées par le test

1. `scan` fonctionne désormais sans connaissance préalable des chemins.
2. Les variables, le `PATH`, les emplacements macOS et les gestionnaires usuels
   sont inspectés sans exécuter leurs outils.
3. Une recherche profonde bornée complète les emplacements conventionnels.
4. La signature Android exige plusieurs marqueurs afin d'éviter les faux SDK.
5. Les chemins identiques avec des casses différentes sont dédupliqués sur
   macOS.
6. Les budgets par emplacement et global empêchent un gros dossier de masquer
   les zones suivantes.
7. La couverture heuristique ne peut plus servir de preuve d'absence.

## Corrections validées après ce relevé

- Les diagnostics de symlinks sont désormais regroupés par racine.
- Les toolchains JDK présentes dans les `Dockerfile` sont distinguées des
  toolchains de l'hôte. Sur ce Mac, l'API Java 21 de validation ressort
  `HOST:UNKNOWN` et `DOCKER:MATCHED` grâce à son image Temurin 21.
