# Validation du paquet macOS — Mac 01

- Date : 2026-09-05
- Machine : Mac 01, Apple Silicon
- Version : `0.1.0-mvp`
- Nature : contrôle de packaging sur la machine déjà utilisée pour le scan

## Artefacts produits

- `dev-audit_0.1.0-mvp_darwin_arm64.tar.gz` : Mach-O 64 bits ARM64 ;
- `dev-audit_0.1.0-mvp_darwin_amd64.tar.gz` : Mach-O 64 bits x86_64 ;
- un fichier `.sha256` par archive et `SHA256SUMS` : vérification réussie pour
  les deux architectures et pour une archive ARM64 téléchargée seule.

Chaque archive contient uniquement le binaire `dev-audit`, l'installateur sans
Go `install.sh` et les instructions `INSTALL.md`.

## Test sans Go dans le PATH

L'archive ARM64 a été extraite puis installée avec un `PATH` limité à
`/usr/bin:/bin`. Dans cet environnement :

- l'installateur n'a invoqué ni Go ni Homebrew ;
- `dev-audit version` a retourné `0.1.0-mvp` ;
- un scan explicite au format JSON s'est terminé avec le code `0` ;
- le rapport produit porte la version `0.1.0-mvp` et respecte le contrat JSON.

## Limites du contrôle

Go reste installé sur le Mac, même s'il était absent du `PATH` du processus de
test. Cette vérification ne remplace donc pas le test prévu sur un Mac propre
sans Go. Le binaire Intel a été inspecté statiquement, mais pas exécuté sur une
machine Intel. Ce relevé ne compte pas comme une deuxième machine dans le gate
de validation sur 10 à 15 Macs.
